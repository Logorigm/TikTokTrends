# TrendScout — план, архитектура, источники и ограничения

Документ отвечает на пункты 1–6 раздела «Что я ожидаю»: архитектура, реально доступные источники, ограничения и риски, структура экранов, состав MVP и поэтапный план.

---

## 1. Архитектура

```
┌──────────────────────── app (Android, Kotlin, Jetpack Compose) ────────────────────────┐
│ ui/            Экраны Compose + ViewModel (StateFlow). Тёмная тема, нижняя навигация.  │
│   feed, search, compare, library, settings, detail, ideas, components                   │
│ notify/        WorkManager: периодическая проверка, уведомления                         │
│ data/repo      LibraryRepository (локальная библиотека), VideoLookupService (oEmbed),   │
│                FeedSyncService (JSON-фиды), AiService (GLM / шаблоны)                   │
│ data/remote    OkHttp: Net (ошибки → NetError), OEmbedClient, FeedClient, LlmClient     │
│ data/db        Room: videos, snapshots, region_observations, trends, trend_snapshots,   │
│                ideas, collections, collection_items, notified                          │
│ data/prefs     DataStore (настройки) + SecretStore (Android Keystore, AES-GCM)          │
└───────────────────────────────────────────┬────────────────────────────────────────────┘
                                            │ зависит от
┌──────────────────────── core (чистый Kotlin/JVM, покрыт unit-тестами) ─────────────────┐
│ model/     Video, StatSnapshot, Trend, RegionObservation (страна популярности),         │
│            authorCountry (страна автора — отдельно!), Countries (любой ISO-код)         │
│ scoring/   MetricsCalculator (рост только между замерами), TrendScorer (факторы,        │
│            надёжность, предупреждения), Insights (факты из данных)                      │
│ feed/      FeedEngine (фильтры/сортировки), TrendCatalog (хештеги/звуки/форматы)        │
│ compare/   CountryComparator (общее/уникальное/мультирынок/адаптируемое + размер выборки)│
│ io/        TikTokUrl (парсинг, дата из ID), CsvImporter, JsonFeedParser                 │
│ ideas/     PromptBuilder (GLM), LlmJson (устойчивый разбор), TemplateIdeaGenerator      │
└────────────────────────────────────────────────────────────────────────────────────────┘
                                            ▲
               (опционально) собственный сервер: лицензированные данные + секреты → JSON-фид
```

Ключевые решения:
- **Разделение слоёв.** UI → ViewModel → репозитории/сервисы → Room/сеть. Логика оценки, фильтрации и сравнения — в модуле `core` без Android-зависимостей: тестируется на JVM и переносима на сервер.
- **Новые источники** подключаются как реализация «импортёра» в `ImportedItem` (CSV, JSON-фид уже есть) — остальная система (оценка, сравнение, уведомления) работает с ними автоматически. Новый тип источника = клиент в `data/remote` + строка в `AppContainer`.
- **Local-first / офлайн.** Всё сохранённое (видео, замеры, тренды, идеи, заметки, подборки) лежит в Room; сеть нужна только для oEmbed, фидов и ИИ. Ошибки сети типизированы (`NetError`) и объясняются пользователю.
- **Секреты.** В APK нет ключей. Ключ GLM и токены фидов вводит пользователь, они шифруются ключом из Android Keystore и исключены из бэкапа. Платные/лицензированные источники — только через собственный сервер.
- **Расширяемость.** Страны — любые коды ISO 3166 (имена из локали). Все тексты — в `strings.xml` (русский по умолчанию; новый язык = `values-xx/strings.xml`).

## 3. Ограничения и риски

| Риск | Последствие | Как учтено |
|---|---|---|
| Нет открытого API трендов по странам | Приложение не видит «весь TikTok» | Честный онбординг; Creative Center по ссылке; ручной/CSV-ввод; JSON-фид для лицензированных данных |
| Один снимок статистики выдаётся за рост | Ложные «вирусные» метки | Рост только между замерами; при одном замере — пометка и запрет метки «Перспективный» |
| Путаница страны автора и страны популярности | Неверные выводы о рынке | Раздельные поля и фильтр «что значит страна»; сравнение стран игнорирует страну автора |
| Маленькая выборка | Выводы «о всей стране» по 3 роликам | Порог выборки (10 наблюдений) с предупреждением; показ «наблюдений» по стране |
| Галлюцинации ИИ | Выдуманные звуки/цифры | Промпт запрещает выдумывать; теги «из данных» показываются отдельно зелёным; всё от ИИ помечено |
| Отправка данных провайдеру ИИ | Приватность | Отправляются только тексты тренда и заметки; предупреждение в настройках; ИИ опционален |
| Изменение условий TikTok / ссылок Creative Center | Поломка переходов | Ссылки в одном месте; при неприменении параметров — инструкция выбрать регион |
| Превью oEmbed истекают | Пустые миниатюры | Плейсхолдер; повторный lookup |
| Авторские права | Претензии | Видео не скачиваются, только ссылки и метаданные oEmbed |

## 4. Структура экранов

Нижняя навигация: **Тренды · Поиск · Сравнение · Избранное · Настройки**.

1. **Тренды** — переключатель «Видео / Хештеги, звуки, форматы»; чипы сортировки (быстрорастущие, популярные, новые, активность, под тематику); чипы стран и периода; лист фильтров (смысл страны, дата публикации, тип, категория, просмотры, мин. скорость роста). Карточка: превью, описание, автор и подписчики, дата (с пометкой «из ID видео»), страна популярности / страна автора раздельно, счётчики «на дату», рост (измеренный или «нужны замеры»), хештеги и звук, кнопки «оригинал» и «избранное», метка перспективности только при обоснованности.
2. **Поиск** — локальный поиск; переход в поиск/тег TikTok; добавление видео по ссылке (и через «Поделиться» из TikTok), добавление тренда, импорт CSV; блок Creative Center (страна, 7/30/120 дней, хештеги/песни/авторы/видео).
3. **Анализ видео** — график просмотров по замерам, рост за интервалы 24ч/3д/7д/30д, ускорение, вовлечённость, просмотры/подписчики; журнал замеров; география (автор отдельно, популярность с основанием и надёжностью); связанные теги; разбор оценки; «Почему это может работать» = факты из данных + гипотезы ИИ (отдельно); заметки о первых секундах.
4. **Анализ тренда** — страна и период анализа; динамика публикаций по странам; страны с основаниями; оценка; связанные хештеги и звуки; повторяющиеся элементы и первые секунды; «Почему это может работать»; примеры у разных авторов со ссылками; сохранить / отметить использованным / в подборку / идеи.
5. **Генератор идей** — данные тренда, переданные генератору; параметры (страна, аудитория, жанр из 9, длительность, речь, сложность, эмоция, количество); ИИ (GLM-4.5-Flash) или офлайн-шаблон; для каждой идеи 8 обязательных блоков; сохранение в библиотеку.
6. **Сравнение стран** — выбор 2+ стран и периода; размер выборки; общее; уникальное по стране; уже мультирыночное; новое на одном рынке; адаптируемое (звуки и визуальные форматы).
7. **Избранное** — вкладки: видео, тренды, идеи, в производстве, опубликовано, архив, подборки; поиск; фильтры по стране и жанру; статусы идей; заметки; ссылка на свой опубликованный ролик.
8. **Настройки** — мои страны, тематики, категории; ИИ (адрес, модель, ключ, проверка); источники (JSON-фиды, синхронизация); уведомления (частота, страны, категории, типы); «Источники данных и ограничения».

## 5. Минимальный набор функций MVP (реализован)

- Добавление видео по ссылке/через «Поделиться» с метаданными oEmbed и датой из ID видео.
- Ручные замеры статистики и CSV-импорт → реальная динамика и скорость роста.
- Тренды (хештег/звук/формат/мем/визуальный приём) с замерами из Creative Center по странам.
- Лента с 5 сортировками и фильтрами по странам (с раздельной логикой страна автора / популярность), периоду, дате публикации, категории, просмотрам, скорости роста, типу.
- Прозрачная оценка перспективности с факторами, пропусками, надёжностью и предупреждениями.
- Экраны анализа видео и тренда, сравнение стран, генератор идей (GLM + офлайн-шаблоны).
- Избранное, подборки, заметки, статусы идей, архив использованных трендов, поиск и фильтры — всё офлайн.
- Уведомления WorkManager по данным фидов и библиотеки.
- Состояния загрузки, пустых данных и ошибок (нет сети, таймаут, 401/429, неверный ответ).
