# Оценка перспективности тренда

Реализация: `core/src/main/kotlin/com/trendscout/core/scoring/`.

## Принципы
- Абсолютные просмотры не являются критерием сами по себе.
- **Скорость роста** считается только между двумя реальными замерами. При одном замере доступно лишь «среднее с момента публикации», оно помечается как не-рост и имеет малый вес.
- Каждый фактор используется только при наличии данных; итог нормируется на сумму весов доступных факторов. Отсутствующие факторы показываются пользователю.

## Факторы (вес → нормировка 0..1)
| Фактор | Вес | Нормировка |
|---|---|---|
| Скорость роста просмотров (между замерами) | 0.22 | log10(просм/ч)/5, 100 000/ч → 1 |
| Среднее с публикации (только если рост не измерен) | 0.08 | то же |
| Ускорение (последний интервал / предыдущий) | 0.12 | (x−0.5)/1.5 |
| Вовлечённость (лайки+комм.+репосты)/просмотры | 0.10 | x/12% |
| Изменение вовлечённости между замерами | 0.08 | 0.5 + Δ/4 п.п. |
| Возраст видео | 0.08 | ≤24 ч → 1, линейно до 0 к 30 дням |
| Просмотры / подписчики автора | 0.14 | log10(x)/2; ×1 → 0, ×100 → 1 |
| Разных авторов с тем же тегом/звуком/форматом (30 дней, ваша база) | 0.10 | (n−1)/9 |
| Стран с признаками популярности | 0.08 | (n−1)/4 |
| Рост числа публикаций тега/звука (замеры тренда) | 0.08 | (%/сутки)/50% |

## Метки и надёжность
- Покрытие < 30% или < 3 факторов → «Мало данных», без числа.
- Надёжность: **высокая** — ≥3 замера, покрытие ≥70%, есть география не только из личных наблюдений; **средняя** — ≥2 замера и покрытие ≥45%; иначе **низкая**.
- «Перспективный» — балл ≥65 **и** надёжность ≥ средней. «Наблюдать» — балл ≥45. Иначе «Слабый сигнал».

Пороги эвристические и вынесены в константы — их можно калибровать по мере накопления истории.
