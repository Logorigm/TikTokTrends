# TrendScout — поиск международных трендов TikTok

Android-приложение для авторов контента: помогает замечать тренды раньше массового распространения, сравнивать рынки разных стран и превращать тренды в собственные идеи для роликов.

Главный принцип: **только разрешённые источники и честные данные.** Приложение не парсит TikTok скрытно, не обходит авторизацию и лимиты, не скачивает чужие видео и не подставляет вымышленные тренды. Если данных нет, оно так и пишет.

- Архитектура, источники, риски, экраны и план: [docs/PLAN.md](docs/PLAN.md)
- Методика оценки перспективности: [docs/SCORING.md](docs/SCORING.md)
- Форматы CSV и JSON-фида: [docs/DATA_FORMATS.md](docs/DATA_FORMATS.md)

## Возможности MVP

| Раздел | Что умеет |
|---|---|
| **Тренды** | Лента видео и отдельно хештегов/звуков/форматов. 5 сортировок, фильтры по странам (страна автора и страна популярности разделены), периоду, дате публикации, категории, просмотрам, скорости роста и типу тренда. |
| **Поиск** | Поиск по своей базе, добавление видео по ссылке или через «Поделиться» из TikTok (метаданные через официальный oEmbed), добавление тренда, импорт CSV, быстрый переход в TikTok Creative Center нужной страны. |
| **Анализ** | График по замерам, рост за 24ч/3д/7д/30д, ускорение, вовлечённость, отношение просмотров к подписчикам. Прозрачная оценка: какие данные использованы, чего не хватает, насколько вывод надёжен. «Почему это может работать»: факты из данных отдельно от гипотез ИИ. |
| **Генератор идей** | GLM-4.5-Flash (бесплатно, по вашему ключу) или офлайн-шаблоны. 9 жанров. Для каждой идеи: концепция, сценарий по секундам, первые 2 секунды, кульминация, зацикленный финал, монтаж, звуки и хештеги из данных, адаптация под другую страну. |
| **Сравнение стран** | Что общее, что уникально, что уже распространилось на несколько рынков, что ново и пока на одном рынке, что можно адаптировать. С предупреждением о малой выборке. |
| **Избранное** | Видео, тренды, идеи по статусам (идея → в производстве → опубликовано → архив), архив использованных трендов, подборки, заметки, поиск и фильтры. Всё работает офлайн. |
| **Уведомления** | Новые перспективные видео, резкий рост, распространение в выбранной стране, новое по сохранённым тегам. Пользователь сам выбирает частоту, страны и категории. |

## Сборка

Нужны JDK 17 и Android SDK (platform 35). Проще всего через Android Studio (Ladybug или новее): **File → Open** → папка проекта → **Run**.

Из командной строки:

```bash
./gradlew :core:test            # unit-тесты логики (без Android SDK: CORE_ONLY=1 ./gradlew :core:test)
./gradlew :app:assembleDebug    # APK: app/build/outputs/apk/debug/app-debug.apk
```

Готовый debug-APK собирает GitHub Actions при каждом push (workflow **Android CI** → артефакт `TrendScout-debug-apk`).

### Установка APK на телефон

1. Скачайте `app-debug.apk` (артефакт CI или из локальной сборки) на телефон с Android 8.0+.
2. Откройте файл и разрешите установку из этого источника, когда Android попросит.
3. Или по USB: `adb install -r app/build/outputs/apk/debug/app-debug.apk`.

Для публикации соберите подписанный release: `./gradlew :app:assembleRelease` с вашим keystore (настраивается в `signingConfigs`; ключи в репозиторий не кладите).

## Первый запуск

1. **Настройки → ИИ**: при желании вставьте бесплатный ключ GLM-4.5-Flash (open.bigmodel.cn или z.ai) и нажмите «Проверить». Без ключа работают офлайн-шаблоны.
2. В TikTok нажмите **«Поделиться» → TrendScout** у интересного ролика. Внесите текущие просмотры и лайки.
3. Через несколько часов добавьте второй замер. Только после этого появится реальная скорость роста и возможна метка «Перспективный».
4. **Поиск → Creative Center**: откройте топ региона и перенесите заметные хештеги и звуки через «Добавить тренд» (источник «Creative Center»).

## Структура проекта

```
core/   чистый Kotlin: модели, расчёт метрик, оценка, лента, сравнение стран, импорт, промпты (unit-тесты)
app/    Android: Compose UI, Room, DataStore, Keystore, OkHttp, WorkManager
docs/   план, методика оценки, форматы данных
tools/  gen_strings.py — генератор res/values/strings.xml
```

Добавить язык: создайте `app/src/main/res/values-en/strings.xml` с теми же ключами.
Добавить источник данных: поднимите сервер, отдающий JSON в формате из [docs/DATA_FORMATS.md](docs/DATA_FORMATS.md), и подключите его в настройках. Либо реализуйте новый клиент в `app/.../data/remote` и зарегистрируйте его в `AppContainer`.
